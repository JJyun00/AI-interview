# AI-interview
# AI 면접관

- 이력서나 글을 올리면 AI가 피드백을 주고, 그 내용을 바탕으로 AI 면접관과 모의 면접을 볼 수 있는 사이트
- 신입 개발자 채용 면접을 대상으로 함

## 사용자 흐름
1. 이력서나 글을 붙여 넣고 지원 직무를 입력한다
2. 구조화된 피드백(강점, 약점, 개선점, 점수)을 받는다
3. "면접 시작"을 누르면 피드백을 아는 면접관이 질문한다
4. 면접을 끝내면 총평을 받는다

## MVP 범위
- 포함: 텍스트 입력, 피드백 결과 화면, 스트리밍 채팅 면접, 면접 총평, 기록 저장
- 제외: 음성 면접, 회원가입과 결제, 다국어, 파일 업로드
